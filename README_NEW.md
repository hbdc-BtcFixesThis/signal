# signal

If every individual ran a server what infrastructure would be considered critical? How do we go from phones reaching out to counterparty risks masquerading as products and services to phones reaching out to a trusted home base? Bitcoin stitched together a solution to the byzantine generals problem by using existing technologies and allowing the market and real world physical constraints to dynncamically solve the problem in real time. This gives us back our right to value expression. Because bitcoin is really just rules and data encoded on peoples machienes its easy to see why it could be tempting to use that space to store critically important information. The ledger becomes practically indistructable. Putting data on the ledger in turn makes that information practically indistructable. This however adds the amount of data needed to store the ledger. As the ledger grows in size the number of people capible of running a node that has the capacity required to store the ledeger declines. That last part is a worst case scenario. Since bitcoin transactions can contain arbitrary data users can use it to place data that has nothing to do with the transaction itself. This is not an inevitable future. One alternate future one can imagine is one in which there exists a market for all that other data. One that allows for people to own their own bank by making it as small as possible to contain all the data about value transfer and nothing more. There will of course always be debates about what is to be considered arbitrary vs transactional data. This is not a space for that. This is a space that exists to absorb all that data. That way users that care about self soverignnty can run their own bank, fasicilitate and verrify their transactions, and audit the ledger aytime they wish. This network does the same for everything other then monetary value. It depends on bitcoin but bitcoin knows nothing about it. Lets say that there was some information you wated to get onto a distributed datastore. What would be an example? Maybe a url? Lets start with that. Lets say we also have 1 bitcoin. You could theoretically take that bitcoin, create a transaction and add the url to it, and as long as it is valid itll be picked up by some miner thatll collet the fee on or off chain before adding it to the chain. Many such scenarios can be envisioned. Of the data that this new transaction is made up of lets say %x percent was non monetary. Now that that data is in the utxos (ie its unspent) its even more accessible to clients who refer to external services to store bitcoins full history while they only store utxos. That url would still be in the history if the coin where spent but it would not be in the set of utxos so the thing that changes there is the number of copies of the data (which in turn affects its accessibility). I would like to explicitly state that this is not condoned by the author. These are just observations. They are made in an attempt at imagining a better world where truth is easier to come by because lying becomes too costly. If what has been written so far is even dirrectionally correct, lets imagine a new future. How would the user trying to propagte the url with most of the same or even better tradeoffs without compromisinng bitcoin. Lets say the user instead ran two pieces of software. Since he was going to use bitcoin to districute the data in the first place he already has that. Now imagine he has another piece of software. This one is called Signal. It too connects to other Signal nodes like it that agree on what it means to be a Signal node. To use space on this network effectively means storing innformation other other users machines. The way the size of the dataset is capped is by using bitcoin as a cost function. As new data comes in the data must include a signature of the data. The information being signed includes the amount of bitcoin being allocated to the data (more on this later) along with some other metadata like the pubkey signing the transaction. However this is just software. Which means that there is no company, foudation, org, etc. So where does the bitcoin go? You keep it. But if I keep it then how do we know that its actually being "allocated" to it. We use the pub key to the bitcoin you own. That means that the cost to acquire the space on this network is the cost to acquire the bitcoin you own. All data is then ranked by # of sats divided by the size of the data. Users that run Signal nodes choose how large of a dataset they want to hold. If the data signal and sgnature is valid then the data gets stored and is publically  accessible by everyone unntil those stats are spent. Just as the cost to acquire space on this network is the cost of acquiring btc the cost to take it off is to spend that utxo backing the data (Note: who you sennd the money to is irrelivent. As long as the utxo is spent this is true. You can send it back to youself on a different address and all else stays the same). Let the games begin.
